Landing Page — The Odin Project
--

**I. English Version.**

The "Landing Page" project will be created as assignment for the HTML & CSS within [The Odin Project (Foundations Course)](https://www.theodinproject.com/). The main goal of this project is to recreate the design from scratch using HTML and CSS stylesheets. The designed website will be a landing page consisting of key sections.

---

Skills Used

The project will allow me to consolidate and practically apply HTML/CSS concepts:

1. HTML5.
2. Advanced CSS Layouts (Flexbox).
3. Box Model.
4. Working with Git and a GitHub repository.
5. Clean, readable CSS code with a logical structure.
---

Technologies Used

1. HTML5 (Semantic structure)
2. CSS3 (Flexbox, Box Model)
3. Git & GitHub
4. Working on Ubuntu.
